# bump_arena (Solana)

Anchor program that escrows BUMP stakes for one match, then pays players by final balance. Port of `contracts/src/BumpArena.sol`. Spec: `docs/handoffs/solana/01-contracts.md` (C2).

Anchor 1.0.1, anchor-spl 1.0.1 (classic SPL Token, 9 decimals), solana-cli 3.1.x, Rust 1.89 SBF toolchain. Program id `3LDXSuMuzP33VZ31sar4ZN1YB13pta7NRuR6aDJmwVgz` (keypair `target/deploy/bump_arena-keypair.json`, not committed).

## Build and test

```bash
cd solana
flock /tmp/bump-build.lock env PATH=$HOME/.cargo/bin:$PATH anchor build     # target/deploy/bump_arena.so + target/idl/bump_arena.json
flock /tmp/bump-build.lock env PATH=$HOME/.cargo/bin:$PATH cargo test -p bump_arena -- --nocapture
```

`PATH=$HOME/.cargo/bin` is needed so `anchor build` finds the rustup cargo (the `+toolchain` directive fails with `/usr/bin/cargo`). Tests run in-process on LiteSVM against the built `.so`, no validator. Run `anchor build` before `cargo test`.

After changing the program, copy the IDL and regenerate the client:

```bash
cp target/idl/bump_arena.json idl/bump_arena.json
pnpm --filter @bump/sol-client generate
pnpm --filter @bump/sol-client test
```

## Accounts

| Account | Seeds | Size | Rent |
|---|---|---|---|
| `Config` | `["config"]` | 190 B | 2,213,280 lamports |
| `Match` | `["match", match_id]` | 594 B | 5,025,120 lamports |
| vault (token account) | `["vault", match_id]`, authority = `Match` PDA | 165 B | 2,039,280 lamports |

`Match` layout after the 8 byte discriminator: `match_id[32] status:u8 stake:u64 start_balance:u32 max_players:u8 player_count:u8 players[8x32] session_keys[8x32] vehicles[8] refunded:u8 join_deadline:i64 settle_deadline:i64 bump:u8 vault_bump:u8`. Status: 0 None, 1 Open, 2 Started, 3 Settled, 4 Cancelled, 5 Refunding. `settle_deadline = join_deadline + settle_window_s`, fixed at open.

The operator pays rent for a match (about 0.00706 SOL). There is no close instruction in C2, so it is not reclaimed.

## Instructions

| Instruction | Signers | Notes |
|---|---|---|
| `initialize` | admin | accounts: admin, config, mint, treasury, token_program, system_program |
| `open_match` | operator | creates Match and vault; blocked while paused |
| `join_match` | player (fee payer may be anyone) | player_token must be a BUMP account of the player; blocked while paused |
| `start_match` | operator | needs at least 2 players |
| `settle` | operator and result_signer | remaining accounts: one writable BUMP token account per seat, in seat order |
| `cancel` | operator | Open, or Started with fewer than 2 players; remaining accounts as in settle |
| `claim_refund` | none | after `settle_deadline` for Started/Open/Refunding; one seat per call |
| `set_paused` | admin | only blocks new opens and joins; settle, cancel and refunds still work |

Errors (codes start at 6000, in this order): Paused, MatchNotOpen, MatchFull, JoinClosed, AlreadyJoined, NotEnoughPlayers, BadStatus, SettleWindowOver, SettleWindowOpen, LengthMismatch, NotZeroSum, BadRemainingAccounts, AlreadyRefunded, NotAPlayer, Unauthorized, then BadRanks, BadVehicle, InvalidParams (added to port the EVM checks).

## Client

`packages/sol-client` (`@bump/sol-client`) is generated by Codama from `idl/bump_arena.json` into `src/generated` (committed), plus `PROGRAM_ID`, `findConfigPda()`, `findMatchPda(matchId)`, `findVaultPda(matchId)` (accept `Uint8Array` or hex string), `withRemainingAccounts(ix, addresses)` for settle and cancel, and `deployments` from `solana/deployments/devnet.json`. The `initialize` instruction input names the treasury argument `treasuryArg` (the account is `treasury`).

## Deploy (PM only)

The script deploys the program, creates the BUMP mint (9 decimals, mint authority = the given pubkey), creates the treasury token account (owned by the deployer unless `--treasury-owner`), calls `initialize`, and writes `deployments/devnet.json`. It refuses mainnet URLs.

```bash
cd solana
flock /tmp/bump-build.lock env PATH=$HOME/.cargo/bin:$PATH anchor build
ANCHOR_WALLET=~/.config/solana/bump/deployer.json pnpm deploy:devnet -- \
  --mint-authority <mint-authority pubkey> \
  --operator <relayer pubkey> \
  --result-signer <result-signer pubkey> \
  [--rpc https://api.devnet.solana.com] [--stake 100000000000] [--start-balance 100] [--settle-window 600]
```

`--operator` must be the key that opens, starts and settles matches (the server relayer). Defaults: stake 100 BUMP (100000000000 base units), start balance 100, settle window 600 s. The deployer is the upgrade authority and config admin.

Local rehearsal (throwaway keys, never touches devnet): start `solana-test-validator --mint <wallet pubkey>`, then `ANCHOR_WALLET=<wallet> pnpm deploy:local -- ...`; it writes `deployments/local.json` (git ignored). Stop the validator afterwards.
